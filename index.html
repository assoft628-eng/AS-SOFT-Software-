Push App Update (index.html)

"Push Update" replaces the app's code (app_config/html) for every user automatically the next time they open or refresh it. "View Current Code" loads the currently-live pushed code into the box above so you can inspect or edit it before re-pushing. "Delete Pushed Update" removes app_config/html entirely (users then keep using whatever copy of the app they already have loaded/cached, until you push again) — existing user data (stock, sales, purchases, etc. under users/*/data) is stored separately and is never touched by any of these actions.

🐙 GitHub Auto-Update Source

Paste the raw GitHub URL of your index.html (e.g. https://raw.githubusercontent.com/user/repo/main/index.html). Every time the app opens, it silently checks this URL and — if the version marker inside the file (<!-- AS_SOFT_VERSION:N -->, must be near the very top) is higher than the version already applied — it auto-downloads and applies that code with NO confirmation popup. Just committing & pushing a new index.html to GitHub (with the version number bumped) is enough; nothing needs to be pasted here again unless the URL itself changes.
