"Push Update" replaces the app's code (app_config/html) for every user automatically the next time they open or refresh it. "View Current Code" loads the currently-live pushed code into the box above so you can inspect or edit it before re-pushing. Checking...

If a new update is available, it is checked and applied automatically as soon as the app is opened — even before the login screen appears — so the new version loads on its own. You don't need to download anything or manually save/overwrite this file. Once the app is open, you can also check manually anytime using the "Check for App Update" button above; if a new update is found, confirming it will apply it right away. Your data (stock, sales, purchases, etc.) is never affected by this process, since it is stored separately in Firebase.
